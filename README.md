# Sistema de Garage

Sistema desarrollado en Java para administrar espacios de estacionamiento.

## Funcionalidades

- Registrar ingreso de vehículos.
- Registrar salida de vehículos.
- Listar vehículos estacionados.
- Consultar estado del garage.
- Generar reportes.
- Validar capacidad disponible.
- Calcular costo total según tipo de vehículo.

## Tipos de vehículos

- Moto: ocupa 1 espacio, $700 por hora.
- Auto: ocupa 2 espacios, $1000 por hora.
- Camión: ocupa 4 espacios, $1500 por hora.
